# Terminal Demo

Bare `tweetkb` prints usage and exits. It does not open a menu.

```bash
tweetkb tui          # search + related
tweetkb wizard       # numbered command menu
tweetkb search rust
tweetkb digest
```

`tweetkb wizard` prints:

```text
1. Collect bookmarks
2. Search
3. Analyze (offline)
4. Stats
5. Export
0. Quit
```
